# Theo Assistente IA

Assistente pessoal de inteligência artificial em Python com Flask e Gemini.

## Visão geral

Este projeto oferece uma interface web simples para conversar com uma IA pessoal, guardar memórias e manter contexto por conversa.

## Requisitos

- Python 3.10+
- Conta Google Gemini com chave de API

## Configuração

1. Crie um ambiente virtual e instale dependências:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Defina as variáveis de ambiente:

```bash
export IA_SECRET_KEY="sua-chave-secreta"
export IA_PASSWORD="sua-senha"
export GEMINI_API_KEY="sua-chave-do-gemini"
export GEMINI_MODEL="gemini-3.5-flash-lite"
```

## Execução

```bash
python app.py
```

A aplicação ficará disponível em:

```text
http://127.0.0.1:5000
```

## Estrutura

- `app.py`: aplicação Flask
- `config.py`: configurações e ambiente
- `db.py`: banco SQLite
- `services/`: integração com Gemini e memória
- `templates/`: páginas HTML
- `static/`: CSS
